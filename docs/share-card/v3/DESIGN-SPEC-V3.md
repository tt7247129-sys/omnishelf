# 分享卡 · 艺术化迭代 v3(第二稿,待确认)

> 样张:`01-date-paper.png` … `06-gallery-night.png`,总览 `all-six.png`。
> 尺寸 1080×1440;全部用 App 已有色板,由内嵌 Canvas 渲染。

## 一、这一版加了什么(以及为什么)

| 手法 | 做了什么 | 为什么它能让人想分享 |
|---|---|---|
| **朱砂印章** | 每张卡一枚 74–86px 的朱砂方印,内嵌「書 / 讀」白字,边缘做轻微压印斑驳 | 一枚印章就是一次签名。它让卡片像"手作",而不是模板;也成了 OmniShelf 唯一可被认出的图形符号 |
| **纸张肌理** | 纸卡叠加 5% 噪点,夜卡叠加暗角 | 屏幕上的"纸"比纯色更耐看,截图到朋友圈不显廉价 |
| **票根式页脚** | 底部用虚线打孔分隔,缺口半圆压在边缘;左介绍词、右二维码 | 卡片像一张可以撕下来的票根,天然带"收藏/分享"的心理暗示;二维码不再像贴上去的补丁 |
| **宋体引文** | 引文与书名改用宋体(Songti),字号 44–54、行距 78–92 | 黑体像通知,宋体像书。文学感直接决定"这段话值不值得发" |
| **光学边距** | 左边界随字号做光学收缩(如「21」的 8px 内收),大数字与正文对齐 | 机器对齐会显得呆;光学对齐让版面"像人排的" |
| **开引号** | 卡 6 把 330px 的「“」压在首行后面 | 一个"半个符号"比整句更抓眼,是海报常用手法 |

## 四、每张卡必有的三件事(用户要求)

1. **产品介绍**(小字,票根左侧):
   `OmniShelf：一个不给你看广告的阅读器，34 种格式、离线朗读、55 种语言。`
   → 资源 `share_card_intro`,**55 个语言各一份**,已写入 56 个 `strings.xml`(742 键零差异)。
2. **二维码**(票根右侧):内容取 `share_card_url`,当前 `https://omnishelf.cc`;
   上线后改这一处即切到商店链接,代码不用动。二维码下方固定小字 `omnishelf.cc`。
3. **印章**(签名):每张一枚,位置随构图走(卡 1/3/6 在内容块尾部,卡 2/4 压在封面角上,卡 5 在顶栏右侧)。
4. **扫码引导**(第二版新增):二维码上方一行小字,中文「扫码 · 读同款」,英文 "Scan to read";
   资源 `share_card_scan`,**55 个语言各一份**,已写入 56 个 `strings.xml`(743 键零差异)。

> **已去掉的东西**:票根左下角那行 `OMNISHELF` 品牌名。介绍词开头就是 OmniShelf,
> 同一块 200px 内出现两次是重复;卡 5 顶部的报头式品牌名同样已去掉。

## 五、与 App 实现的映射

| 设计手法 | 实现方式 | 成本 |
|---|---|---|
| 印章 | `Canvas` 画圆角矩形 + 宋体单字 + 少量噪点 | 极低 |
| 纸张肌理 | `Bitmap` 噪点叠加(预生成一张 256×256 噪点图平铺) | 极低 |
| 暗角 | `RadialGradient` | 极低 |
| 票根打孔 | `DashPathEffect` + 两个圆 | 极低 |
| 宋体引文 | **需内置中文衬线子集**(思源宋体,常用 3500 字约 2–3MB) | +2–3MB |
| 二维码 | 加入 `com.google.zxing:core`(约 500KB),按 `share_card_url` 实时生成 | +500KB |
| 日期本地化 | `SimpleDateFormat` + 系统 `Locale` | 零 |
