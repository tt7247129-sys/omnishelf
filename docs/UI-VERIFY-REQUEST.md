# 请在手机上验收这三屏

安装包:`out/OmniShelf-ui-check.apk`(arm64,49MB,覆盖安装即可,不用卸载)

装好后打开,依次看这三处,截图发回即可。**不用写文字说明**,我看图就够。

## 一、书架(默认打开"最近")

1. 打开应用,应该直接停在 **Recent** 页
2. 读过的书应该显示进度百分比和一条进度线
3. 切到 **Library**,封面右上角应该有一个**墨绿色小圆角标签**写着百分比

**要看的是**:绿色是不是偏灰、发闷;标签会不会挡住封面上的书名。

## 二、阅读页(随便开一本书,点屏幕中间)

1. 顶栏应该只有 **4 个图标**(列表 / 月亮 / 全屏 / 笔)
2. 底栏应该只有 **4 个图标**(搜索 / 书签 / 目录 / 页码)
3. 页面底部应该能看到**时间**和**电量**

**要看的是**:少掉的图标会不会让你找不到某个功能;时间电量会不会和正文挤在一起。

## 三、任意一个对话框(比如设置 → 书库文件夹)

**要看的是**:按钮和图标现在是**灰色**还是**绿色**。

这一项最关键——我上一轮把内部一个叫 `tint_gray` 的颜色从青色改成了灰色,
但它被 106 处引用,我无法确认是不是有的地方因此变得太暗、看不清。
