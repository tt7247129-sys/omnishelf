# Where to Read

Finding a book is a different skill from reading one, and the advice available for it is
mostly a list of links. A list answers "where do free books exist" and not the question
that matters: which of these will give you a file that opens correctly on the device you
own, with metadata that lets you find it again in six months.

So each guide here compares sources on the things that actually differ between them —
what formats are offered, whether a download needs an account, how good the metadata is,
how the site behaves when you are on a phone, and what its privacy policy says about
what happens to the fact that you looked.

Two boundaries hold throughout the column.

**Everything recommended is legal.** Public-domain collections, open-access catalogues
and library lending. There is no list of grey-market sites here, no "alternative
mirrors", and no suggestion that a paywall is optional. If a source is not lawful in the
jurisdiction it operates in, it does not appear.

**Nothing here is paid placement.** Where a service has an affiliate or revenue-sharing
programme — and several do — the article says so in the sentence where it comes up.

The goal is not a longer list. It is that you stop re-downloading the same three books
and start using the catalogues that already have what you want.
