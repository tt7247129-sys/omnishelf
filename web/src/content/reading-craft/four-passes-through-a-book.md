Most advice about reading assumes one speed: slow. Slow is right for some books and ruinous
for most. The useful question is not how slowly to read but how many passes to make, and for
how long.

## The first pass: inspection

Ten minutes, no notes. Read the table of contents, the first and last chapter, the headings,
the index if there is one, and the back cover. The goal is a map and a decision: does this
book deserve a second pass?

This pass is cheap, and almost nobody makes it. Libraries are full of books people stalled
in because they started a slow read on page one of a book they did not need to finish.

## The second pass: analytic

The pass people mean by "reading". One book, one argument at a time: what is the claim, what
is the evidence, where does it break? A pencil and a margin are enough; the reader's
highlights and notes exist for the books that survive this pass.

A practical limit: if a book has not earned a second pass by page 80, it probably will not.
Closing it is a legitimate outcome, not a failure.

## The third pass: synoptic

Several books on one question, read against each other. This is the pass where a highlight
stops being a bookmark and becomes evidence: you are building an answer, and you need to know
where each piece came from.

The work here is comparison, not consumption. Read the same question into four books and the
fifth becomes easy.

## The fourth pass: return

The one nobody names. A month later, go back through the highlights and the margin notes, not
the book. Whatever still reads as true is probably yours; whatever reads as obvious was never
yours. This pass is where most of the value of the whole thing actually appears, and it takes
twenty minutes.

## Deciding before you start

Before page one, ask which pass you are making and write it down. Inspection is a ten-minute
decision; analytic is a promise measured in hours; synoptic is a project; return is a habit.
Most books deserve the first, some deserve the second, a few deserve the third — and every
book you finish deserves the fourth.

A reader that keeps highlights with the book makes the fourth pass possible. That is a
feature, not a slogan: the return pass is the whole reason `OmniShelf` stores notes alongside
the text instead of exporting them somewhere else.
